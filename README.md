# Automação de Bot para Telegram 🤖

Este projeto foi desenvolvido como parte dos meus estudos em **Ciência da Computação** e prática de **Algoritmos e Lógica de Programação**. O objetivo é aplicar conceitos de automação e integração de APIs utilizando Python.

## 🚀 Funcionalidades
- Interface de comunicação via Telegram.
- Estrutura lógica para processamento de comandos.
- Gerenciamento seguro de credenciais (Variáveis de ambiente).

## 🛠️ Tecnologias Utilizadas
- **Python**: Linguagem principal.
- **python-dotenv**: Para segurança e gerenciamento de tokens.
- **Telegram Bot API**: Integração com a plataforma.

⚠️ **Em Desenvolvimento**: O projeto está sendo reestruturado para otimização da lógica de resposta e tratamento de dados.
